# Amostragem Documental

## 1. Objetivo

Desenvolver, documentar e aperfeiçoar uma metodologia técnica,
reprodutível e operacional para amostragem de documentos arquivísticos.

## 2. Escopo

O projeto compreende:

- fundamentação arquivística e estatística;
- definição da metodologia de amostragem;
- elaboração do Manual Técnico de Amostragem Documental;
- desenvolvimento de planilhas de cálculo;
- desenvolvimento de rotinas VBA;
- testes e validação dos procedimentos;
- documentação técnica;
- revisão e aperfeiçoamento da metodologia.

## 3. Produtos

- Manual Técnico de Amostragem Documental;
- planilhas de cálculo;
- rotinas VBA;
- procedimentos operacionais;
- modelos e formulários;
- documentação metodológica.

## 4. Tecnologias e métodos

- Arquivologia;
- Estatística;
- Amostragem probabilística;
- Excel;
- VBA;
- documentação técnica.

## 5. Estrutura

| Diretório | Finalidade |
|---|---|
| `docs/` | documentação técnica e metodológica |
| `src/` | códigos, macros e ferramentas |
| `data/` | dados utilizados no desenvolvimento |
| `results/` | resultados, análises e produtos derivados |
